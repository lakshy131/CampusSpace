# CampusSpace

CampusSpace is an Android application built using Java and Firebase to improve campus communication and management. The app provides features like event updates, grievance management, schedules, announcements, and an admin dashboard for better student interaction and organization.

## Features
- Student Login & Registration
- Admin Dashboard
- Event Management
- Grievance Management
- Schedules & Announcements
- Firebase Authentication
- Real-time Database Integration

## Tech Stack
- Java
- Android Studio
- Firebase
- XML
